# BB 실사 데이터 사전 검증 및 중단 보고서

작성일: 2026-11-08. 상태: **STEP 1 미통과 — 실사 visible mask 신뢰성 미확보**. 지시된 중단 조건에 따라 STEP 2의 학습용 데이터 구축과 STEP 3 학습·평가는 실행하지 않았다.

## 검증 범위 및 결과

- 실사 GT와 카메라 JSON은 `real_bb100_20261108/BB_obj04/scene_gt_obj04.json`, `scene_camera_obj04.json`이다. 100개 GT ID 각각에 해당하는 undistorted RGB가 정확히 한 장씩 존재하며, GT의 회전·이동값과 같은 프레임 번호의 `poses_obj04/pose_*.npy` 값이 일치한다. RGB 전체는 428장이다. 이는 파일명과 수치의 대응 검사이며 라벨의 물리적 정확도 전체를 보증하지 않는다.
- 43번은 `rgb_undistorted/APPROACHING/000043.jpg`, 1280×720이다. CAD SHA-256은 `0933ba753a7aa8d673df6fa180e35807869903661b1bc8d1419ebb0ac890424f`이다. 해당 pose의 원본 translation 및 K 값은 로컬 결과 JSON에 보관한다. 값이나 단위를 수정하지 않았다.
- 기존 `generate_xyz_v2.py`의 CPU 삼각형 min/max 깊이 렌더러를 재사용했다. 원본 방식과 같이 양면 깊이를 이용하고, 모델 bounds로 정규화하여 8비트 XYZ 순서의 OpenCV PNG를 저장했다. 기존 코드에서는 비연속 대칭을 고려하며 연속 대칭은 이산화하지만, 이 객체의 기존 models_info에는 대칭 항목이 없다. VisPy 원본과 비트 단위 동일성은 검증되지 않았다.
- 43번 전체 CAD pseudo mask는 15,688픽셀(전체의 1.70%), bbox는 [381, 214, 178, 153]이다. 그림상 전체 투영은 물체와 대체로 일치하나, 경계 정합을 독립적인 정답 마스크와 정량 비교하지 못했다. 유효 좌표 NaN/Inf는 없고, 독립 광선 교차 10점의 최대 깊이 차이는 약 1.3e-12 mm이다. 8비트 복원 좌표의 재투영 오차 99백분위는 front 0.361 px, back 0.447 px다. 정규화 범위를 벗어난 최대치는 약 0.00433이며 클리핑했다. 이 수치는 계산의 자기 일관성이지 GT pose 정확도의 독립 검증이 아니다.
- 렌더링은 픽셀 중심 +0.5에서 깊이를 계산하고 기존 PBR 생성 규약대로 정수 픽셀 좌표로 역투영한다. PBR에서 사용된 구현을 재사용했으나 이번 실행에서 기존 PBR 라벨과 픽셀별 비교는 수행하지 않았다.
- 43번 출력 마스크는 **전체 CAD pseudo mask**다. 실측 visible mask가 아니며, PNG의 배경 값 0은 유효 XYZ가 아님을 별도 마스크로 구분해야 한다. 기존 로더는 `mask_visib`, `bbox_visib`, `scene_gt_info.json`과 front/back PNG를 사용한다.

## 중단 근거

실사 데이터 폴더에서 정답 visible mask나 이를 검증할 독립적인 depth를 확인하지 못했다. 기존 투영 이미지 221번 등에서는 그리퍼가 물체를 가리는 것이 보인다. 전체 CAD 렌더링을 visible mask로 복사하면 가려진 픽셀에 잘못된 마스크 및 좌표 감독이 들어간다. 43번의 시각적 정합과 기하학적 자체 검사는 100장의 마스크 신뢰성을 증명하지 못하므로 명시적인 중단 조건에 해당한다.

## 재개를 위한 작업

1. 실사 프레임별 visible mask를 별도로 주석하고, 그리퍼·로봇에 가려진 영역과 모호한 경계를 제외한다. 자동 분할을 쓰더라도 독립 검수된 표본과 IoU·경계 오차를 비교하고 실패 프레임을 수정한다. 전체 렌더링 마스크는 amodal pseudo mask로만 보관한다.
2. PBR 기존 분할(`runs/baseline_seed42_20261103_214353/checks/split.json`: train 80, val 20)을 유지한다. 실사는 촬영 사이클 및 pose 유사도를 함께 검사하여 분할 간 누출을 배제하고 독립 평가셋과 중복 여부도 확인한다. 아직 BB 분할은 정하지 않았다.
3. 마스크와 포즈 품질이 검증된 뒤 100장 변환 및 전체 검증, seed 42의 smoke test, 본 학습과 동일한 oracle ROI 평가를 순차 실행한다. GT bbox 사용 결과는 end-to-end 결과로 표현하지 않는다.

GPU 확인 시 RTX 5090에는 그래픽 프로세스만 표시되고 메모리 485 MiB가 사용 중이었다. 이는 확인 시점의 상태이며 향후 학습 전 재확인이 필요하다. 기존 원본·체크포인트·평가 결과는 변경하지 않았다. 신규 산출물은 권한 범위 내 별도 디렉터리 `HCCEPose/bb_real_preflight_20261108`에 저장했다.
