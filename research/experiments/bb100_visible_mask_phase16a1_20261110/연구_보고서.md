# Phase 16A-1 — BB100 Visible Mask 후보 검증

## 결론

10장 모두에서 CAD amodal, SAM 후보, CAD∩SAM 후보와 불확실 영역을 생성했다. 이 결과만으로 **visible mask의 정확도나 자동 학습 가능성을 인증할 수 없다**. SAM은 CAD 투영에 있는 구멍을 메우는 경향이 있고, CAD 교집합은 투영 구멍을 구조적으로 되살리지만 CAD 정합 오차와 그리퍼 오검출을 해결한다고 보장하지 않는다. 100장 무검수 자동 승인 또는 학습용 GT 사용은 **NO-GO**다. 후보를 수동 보정하기 위한 초기값으로 제한적으로 검토할 가치는 있다.

## 자료와 선정

Phase 14의 ACCEPT 검수·카메라·Pose 대응, Phase 15 CAD 투영, Phase 15B의 배치 불확실성을 참조했다. BB는 가림 없음 39장, 부분 가림 61장이다. 선정은 사용자 검수표의 프레임 단위 가림 상태이며 픽셀별 가림 정답이 아니다.

| 가림 없음 | 부분 가림 |
|---|---|
| 043, 247, 383, 420 | 075, 235, 099, 221, 340, 359 |

총 9개 Pose 그룹으로 구성했다. 235/247은 동일 Pose에서 그리퍼 상태를 비교하기 위해 의도적으로 함께 선택했다. 앞뒤 촬영 구간 및 4장의 기존 SAM 사례도 포함한다. 선정 이유와 이미지 경로, 픽셀 면적은 [selected_frames.csv](selected_frames.csv)에 있다. 표본은 편의 선정으로 BB100 전체 실패율 추정에 사용할 수 없다.

## 생성 방법

- **A — CAD amodal:** Phase 15 CPU 렌더 마스크를 복사했다. CAD의 투영 구멍과 전체 물체 실루엣은 표현하지만 실제 그리퍼 가림을 제거하지 않는다. visible GT가 아니다.
- **B — SAM 2.1 Hiera Tiny:** 기존 로컬 모델·체크포인트를 재사용했다. 043/075/235/247은 과거 선택 후보를 그대로 가져왔고, 383/420/099/221/340/359만 신규 추론했다. CAD bbox와 CAD 내부 어두운 점 한 개를 프롬프트로 사용하고 SAM 자체 점수가 가장 높은 3개 후보 중 하나를 선택했다. 점이 구멍·그림자·그리퍼일 수 있으며 SAM 점수는 정답 정확도나 보정된 신뢰도가 아니다. 모델 출력은 전부 `NOT_GT`다.
- **C — CAD∩SAM:** B와 A의 픽셀 교집합으로 CAD 바깥 SAM 영역 및 CAD가 투영한 구멍을 제한한다. 하지만 그리퍼가 두 마스크 모두에 포함되면 남고, CAD가 빗나가거나 SAM이 물체 일부를 빼면 참 객체도 사라질 수 있다.
- **D — 보수적 불확실 표시:** CAD∪SAM을 128로 표시하고 나머지는 0(미지정)으로 둔다. 128은 불확실, 0은 검증된 배경이 아니다. 전경·배경 감독으로 승인된 픽셀은 **0개**다. 이는 실제 occlusion detector가 아니며 학습용 visible mask도 아니다.

원 해상도 PNG 마스크들은 각각 `cad/`, `sam/`, `intersection/`, `uncertainty/`에 있다. D는 0/128 단일 채널이며 A/B/C는 0/255다. D의 0과 128 모두 현재 loss에서 ignore해야 한다. 기존 후보 파일, 원본 이미지, GT 및 체크포인트는 변경하지 않았다.

## 정성 관찰과 구조 검사

| 방법 | 생성 | 구멍 | 그리퍼와 가림 | 수동 보정 필요성 |
|---|---|---|---|---|
| A CAD | 10/10 | 투영된 CAD 구멍 보존 | 가려진 CAD도 전경으로 남음 | 부분 가림에서는 필수; 정렬과 외곽도 확인 |
| B SAM | 10/10 | 여러 구멍을 메움 | 075/235 등 선택 후보가 밝은 그리퍼 상당 부분을 배제하나 완전한 분리는 검증되지 않음 | 구멍·외곽·가림 확인 및 보정 필요 |
| C 교집합 | 10/10 | CAD에 나타나는 구멍은 구조적으로 비전경 | 실제 가림 보장 없음; 교집합의 그리퍼 오검출 가능 | 필수 |
| D 불확실 | 10/10 표시 | GT 판정 없음 | CAD 또는 SAM 지지 영역을 불확실로 표시 | 검증된 감독 신호 없음 |

자동 topology 진단은 CAD 마스크의 8px 이상 닫힌 구멍 중 SAM이 절반 넘게 전경으로 덮는 개수를 세었다. 가림 없음 043은 10/10, 247·383·420은 각각 11/11이었다. 부분 가림 프레임은 CAD 투영 구멍 일부가 실제 그리퍼에 가려질 수 있어 동일 수치를 실제 hole 오류로 단정할 수 없다. CAD 구멍은 렌더링·GT Pose 오차의 영향을 받으므로 이 값도 정확도나 recall이 아니다. [프레임별 구조 진단](cad_hole_diagnostic.csv).

확대 이미지에서 043/247은 SAM 후보가 물체의 실제로 보이는 여러 구멍을 채운다. 075/235/099/221/340/359에서는 중심 그리퍼 주변의 SAM 공백과 CAD 전경 차이가 크지만, 공백 중 실제 물체가 빠진 부분과 가려진 부분을 픽셀 단위로 확정하지 못했다. 얇은 외곽과 물체 경계의 누락·확장, 반사에 의한 분리 여부는 각 이미지의 사람이 확인해야 한다. 이번 선택 후보에서 그리퍼 오검출이 없다고 단정할 수 없으며, 기존 다중 후보 중 075/235 후보 0에는 그리퍼·호스가 포함된 사례가 보고됐다. 포지티브 프롬프트가 그리퍼를 선택할 가능성도 남는다.

## 검수 방법

`BB100_visible_mask_review_windows.zip` 전체를 Windows로 옮겨 압축을 푼 뒤 `index.html`을 Chrome에서 연다. 각 프레임은 전체 RGB 링크와 확대 RGB, CAD, SAM, SAM 오버레이, CAD∩SAM, 교집합 오버레이, CAD-SAM 차이 및 D 불확실 영역을 제공한다. 확대 비교에서는 녹색이 두 마스크 교집합, 빨강이 CAD만, 파랑이 SAM만이다. 이 색은 정답/오답 표시가 아니다. PNG 마스크와 전체 크기 RGB 사본이 ZIP 안에 있다. RGB 사본은 1280×720 JPEG 재인코딩본이며 원본 JPEG는 수정하지 않았다.

선택 방법을 A/B/C/D로 지정한 뒤 ACCEPT/CORRECT/UNCERTAIN 및 메모를 기록하고 CSV를 내보내 보관한다. ACCEPT는 선택한 후보에 대한 사람의 시각 검토 상태이며 이 페이지가 픽셀을 보정하거나 독립적인 정확도를 인증하는 것은 아니다. CORRECT면 기존 별도 마스크 편집 도구에서 구멍과 가림을 보정해야 한다. CSV 가져오기 시 기존에 입력한 상태·메모는 보존한다. 브라우저 localStorage만 믿지 말고 CSV를 저장한다. 실제 가려진 부분은 촬영 영상만으로 판별하기 어려울 수 있으므로 불확실하면 UNCERTAIN을 선택한다.

## 실행·검증

로컬 SAM checkpoint SHA-256 `7402e0d864fa82708a20fbd15bc84245c2f26dff0eb43a4b5b93452deb34be69`. RTX 5090에서 다른 GPU compute 작업이 없음을 확인하고 6장만 추론했다. 모델 로드 후 추론 처리 기록은 약 1.31초, PyTorch peak allocated 583,890,944 bytes(약 557MiB), reserved 679,477,248 bytes(648MiB)이며 전체 GPU 사용량과 같지 않다. 학습이나 추가 외부 다운로드는 없었다. 상세 프롬프트와 모델 내부 점수는 [generation.json](generation.json)에 있다.

10개 후보의 크기·자료형·이진값, 교집합과 불확실 합집합 수식, 선정 분포, ZIP CRC와 이미지·마스크 참조를 검사했다. Linux headless Firefox에서 10개 카드·이미지, 상태·메모 및 CSV 내보내기·가져오기와 새로고침 복원을 시험했다. 실제 Windows Chrome 실행은 미검증이다. Phase 12에서 기록한 입력 307개 해시는 일치했고, 공식 HCCEPose checkpoint SHA-256도 기존 기록과 일치했다. GPU 추론은 SAM 6장만 실행했으며 HCCEPose fine-tuning은 하지 않았다.

## 다음 단계

선정 10장의 후보를 픽셀 단위로 사람이 보정해 참조 마스크를 만들고 구멍·그리퍼·외곽을 별도로 평가한다. 독립 그룹을 나눈 상태에서 누락과 오검출을 측정하고, 다른 가림 형태의 검증 프레임에 재확인한 뒤에만 100장 후보 생성 확대를 판단한다. D의 ignore 영역으로는 현재 실사 손실을 만들 수 없으며, 분할 독립성·공식 대칭 XYZ 타깃·학습 루프의 기존 BLOCKED 판정도 유지된다.
