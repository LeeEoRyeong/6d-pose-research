# Phase 16A-3 — BB100 Visible Mask 참조 구축 준비

## 현재 상태

편집기 및 평가 스크립트는 실행 가능하며 서버는 `127.0.0.1:7867`에서 동작한다. **10장 모두 미저장 DRAFT, REVIEWED 0, ACCEPTED 0**이다. 사람이 픽셀 단위로 수정·승인한 마스크나 Visible Mask GT는 아직 없고, 어떤 초기 후보가 가장 수정하기 쉬운지도 측정하지 못했다. 평가기의 현재 CSV는 헤더만 있고 모델별 정량 정확도는 미산출이다. 사용자 검수 단계에서 작업을 멈춘다.

## 도구 검토

- [SAMannot](https://github.com/gergelydinya/SAMannot): SAM2 기반 영상 라벨링 도구이나 서버에 설치돼 있지 않으며, Windows 브라우저를 통한 원본 삼값 mask와 승인·ignore 규약의 지원을 이 환경에서 확인하지 못했다.
- [CVAT](https://docs.cvat.ai/docs/manual/advanced/annotation-with-brush-tool/): 브러시 및 마스크 가져오기/내보내기를 지원하고 [최근 버전](https://www.cvat.ai/resources/changelog/product-roundup-26-q3-2)은 개별 브러시 Undo/Redo를 지원한다. 서버에 실행 중인 CVAT 인스턴스는 없으며 우리 삼값 규약·상태와의 전체 round-trip은 확인하지 못했다.
- [SegDrawer](https://github.com/lujiazho/SegDrawer): 브라우저 기반 도구지만 자체 README는 수동 brush/eraser 경계가 단일 색이 아닐 수 있음을 설명한다. 0/128/255 정확 저장·Redo·우리 승인 흐름 전체를 검증하지 못했다.
- 기존 `bb_visible_labeler_20261108`은 이 서버에서 재사용 가능한 구조지만 이진 0/255만 지원하며 128 Ignore, Redo, 이번 10장 전체, 여러 초기 후보가 없다. 원본은 수정하지 않고 검증된 canvas/HTTP 접근법을 새 실험 디렉터리에 확장했다. 신규 편집기는 이러한 누락 기능을 제공한다.

## 사용과 저장

서버 실행 컴퓨터에서는 `http://127.0.0.1:7867`을 연다. Windows에서 원격 SSH로 접속한다면 Windows 터미널에서 다음을 실행한 후 같은 주소를 Chrome에 연다.

```bash
ssh -L 7867:127.0.0.1:7867 oylee@<연구서버주소>
```

서버가 종료됐다면 서버에서 아래 명령으로 다시 실행한다.

```bash
cd /home/oylee/projects/HCCEPose_experiments/bb100_visible_gt_phase16a3_20261110
/home/oylee/projects/HCCEPose_experiments/yolo_hcce_rgb_pipeline/.venv/bin/python -B app.py --port 7867
```

프레임과 후보를 선택한 다음 `선택 후보로 초기화`를 누른다. 기본으로 보이는 C는 편의상 설정한 초기값이지 가장 좋은 후보라는 판정이 아니다. 브러시 추가=255, 지우기=0, 불확실=128로 편집한다. 확대 후 구멍·외곽·그리퍼를 확인하고 메모에 수정 사항을 기록한다. Undo/Redo와 저장본 재로드를 지원한다. 후보를 교체하면 저장하지 않은 현재 편집은 바뀌지만 기존 저장 버전은 남는다. 프레임 이동 전 저장하지 않은 수정에 대해 경고한다.

DRAFT·REVIEWED·REWORK은 작업 상태다. **ACCEPTED는 사용자가 버튼을 누르고 실제 픽셀 검수를 확인한 경우에만 기록**된다. 자동 mask를 불러오는 것만으로 저장이나 승인이 이뤄지지 않는다. 변경된 원본 hash나 다른 저장 버전이 감지되면 저장을 거절한다. 동일 출력 폴더에 여러 서버를 동시에 실행하지 않는다.

저장은 `annotations/<frame>/versions/<revision>/`에 새 버전으로 쌓인다. `working_mask.png`는 1280×720 단일 채널 0/128/255이며, `metadata.json`에 초기 후보·입력/마스크 hash·상태·부모 버전·메모가 기록된다. `annotations/frame_status.csv`는 최신 상태 목록이다. UI가 픽셀 단위 판정의 정확성을 자동으로 확인하는 것은 아니다.

`evaluation_foreground_255.png`와 `evaluation_valid_255.png`는 **같이** 사용한다. 전자는 255 foreground만, 후자는 Ignore를 뺀 평가 영역만 255로 나타낸다. Ignore가 남아 있는 경우 단독 이진 전경을 완결된 BOP GT로 취급하지 않는다. 별도로 Ignore 픽셀을 사람이 결정해 없앤 후 승인한 경우에만 순수 0/255 작업 마스크를 이진 GT로 검토할 수 있다. 원본 BOP 데이터셋에 자동으로 쓰지 않는다.

## 후보와 가림

10장 전체에 A CAD amodal, B SAM2, C CAD∩SAM2가 있다. D SAM2−RobotSeg, E CAD∩SAM2−RobotSeg는 실제 RobotSeg가 추론된 부분 가림 6장에만 있다. 다른 프레임의 RobotSeg 결과는 생성하지 않는다. 이전 자동 gripper 조건에서 D는 B와, E는 C와 해당 6장 모두 동일했으며 이 사실은 GT 대비 정확도가 아니다. ROI guided 결과는 별도 탐색으로 후보 D/E에 혼합하지 않았다.

물체 뒤에 가려진 CAD 영역은 visible 전경이 아니다. SAM·CAD·RobotSeg 어느 것도 자동 참조 GT가 아니다. 보이지 않는 구멍이나 외곽은 임의로 0 또는 255로 확정하지 말고 128로 표시한다. 구멍의 실제 배경 노출 여부와 접촉부는 사용자가 영상을 보고 판정해야 한다.

## 평가

사람이 적어도 한 장을 ACCEPTED한 뒤 아래 명령을 서버에서 실행한다. 평가 중 편집 저장을 중지한다. 평가 결과는 매번 새 `evaluations/<시간_UUID>/`에 저장된다.

```bash
cd /home/oylee/projects/HCCEPose_experiments/bb100_visible_gt_phase16a3_20261110
/home/oylee/projects/HCCEPose_experiments/yolo_hcce_rgb_pipeline/.venv/bin/python -B evaluate.py
```

기준 마스크에서 128을 제외하고 나머지 영역에서 IoU, Dice, Precision, Recall, FPR=FP/(FP+TN), FNR=FN/(FN+TP)을 계산한다. 분모 0은 빈 값이며 0점으로 만들지 않는다. 프레임별 결과와 NONE/PARTIAL 및 전체별 매크로 평균을 저장한다. RobotSeg 후보가 없는 프레임은 그 방법의 분모에서 빠진다. `matched_comparison.csv`는 SAM·CAD∩SAM 및 두 RobotSeg 방법이 모두 있는 동일 프레임만 포함한다. **방법 간 비교는 공통으로 ACCEPTED된 동일 프레임과 동일 valid 영역에서만** 해석해야 하며, 전체 매크로 표의 방법별 n이 다르면 직접 비교하면 안 된다. FP는 그리퍼와 다른 배경을 합친 것으로, 독립 그리퍼 GT가 없으므로 그리퍼 전용 precision/recall을 계산하지 않는다.

현재 평가 결과는 ACCEPTED 0, 결과 행 0이다. 정확도를 0으로 계산한 것이 아니라 미측정이다. [평가 정보](evaluations/20261110T133047Z_407ce345/evaluation_info.json), [빈 비교표](evaluations/20261110T133047Z_407ce345/summary.csv).

## 검증

임시 디렉터리의 단위 테스트에서 값 검증, 128 보존, 사용자 확인 없는 ACCEPTED 거절, 버전 보존·충돌 감지, 저장·재로드를 확인했다. synthetic GT에서 TP/FP/FN/TN과 ignore 제외, IoU/Dice/FPR/FNR을 검사했다. 별도 임시 통합 테스트에서는 REVIEWED가 평가되지 않고 승인된 ACCEPTED만 평가되는 것을 확인했다. 이 합성 승인본은 실제 연구 결과가 아니다.

Linux headless Firefox에서 화면 표시와 200% 확대 시 원본 좌표 변환, 포인터 스트로크, Undo/Redo 및 임시 저장을 확인했고 저장된 픽셀 값 128을 원본 위치에서 확인했다. Windows Chrome 실기기는 미시험이다. [오프라인 후보 비교 ZIP](BB100_visible_GT_candidate_review_windows.zip)은 비교 전용 정적 자료이며 서버 편집·승인 기능을 포함하지 않고 실시간 상태가 아니다. ZIP 경로와 CRC를 검사했다.

## 남은 작업

사용자가 10장 각각을 픽셀 단위로 보정하고 승인한 뒤, 동일한 승인 참조·valid 영역에서 후보별 지표와 수정 시간/편의성을 비교한다. 실제 독립 그리퍼 마스크가 없으면 그리퍼 전용 점수는 산출하지 않는다. 10장 품질 및 작업 시간을 확인하고 Pose/물리 배치 그룹의 누출 위험을 해결한 다음 나머지 90장을 그룹별로 순차 검수한다. 학습과 자동 GT 승인은 수행하지 않았다.
