# Phase 15B — BB100 객체 이동 자동 판정 보조

## 판정

**독립 검수 없이 확정 가능한 학습·검증 분할은 없다.** 인접 경계 99개 중 자동 분류는 `LIKELY_STATIONARY` 1개, `LIKELY_MOVED` 0개, `UNCERTAIN` 98개다. 32→34의 파일 SHA-256이 동일해 두 영상 관측이 같다는 사실만으로 정지 가능성을 표시했다. 동일 영상이라도 파일 중복이나 중간 시간대의 물리적 움직임을 배제하지 못한다.

따라서 **물리 배치 경계를 확정하려면 99개 모두 사람 또는 별도의 독립 근거 확인이 필요**하다. 검수 우선순위를 정할 때만 동일 이미지 경계 1개를 낮은 우선순위로 두고, 나머지 **98개를 우선 검토**할 수 있다. 이는 자동화로 안전하게 98개를 확정했다는 뜻이 아니다. 확정된 외부 경계 GT와 검증된 visible-object mask가 없어 자동 판정의 정밀도, 재현율이나 실제 검수 절감률은 측정할 수 없다.

## 데이터 및 기존 검수 보존

Phase 14의 BB 100장, 보정 이미지와 Pose 매니페스트, Phase 15의 99개 경계와 36개 CAD amodal mask를 읽었다. 프로젝트 및 Downloads 검색 범위에서 사람이 내보낸 별도 placement boundary review CSV는 발견되지 않았다. 그래서 새 페이지의 수동 판정은 모두 UNREVIEWED다. 기존 CSV는 읽기만 했고, Phase 15 결과를 수정하지 않았다. 새 페이지는 기존 Phase 15 형식 `boundary_id,before_frame,after_frame,status,note`를 명시적으로 가져올 수 있으며 기존에 편집한 판정과 메모를 덮어쓰지 않는다.

기존 검수 ACCEPT 100은 물체 CAD 투영의 시각 검수다. 이전 Pose나 사용자 검수 기록으로 영상 기반 이동 여부를 자동 확정하지 않았다. Phase 12에 기록된 307개 입력 파일의 현재 SHA-256은 기존 기록과 같았다. GPU 모델 추론이나 학습은 수행하지 않았다.

## 방법: 영상과 GT 지표 분리

1. 각 원본 해상도 이미지의 SIFT와 ORB 특징을 CPU에서 산출한다. 두 특징점이 각각 이전·이후 CAD amodal 투영 mask의 7×7 erosion 내부에 있을 때 객체 후보로 사용한다. CAD에는 그리퍼·구멍·배경과 잘못 정합된 픽셀이 포함될 수 있으므로 **이 조치는 검증된 visible 객체 분할이 아니다**. 밝기만으로 손이나 그리퍼를 제거했다고 가정하지 않는다.
2. 각 방법의 기술자를 ratio 0.75로 매칭하고 대상점 중복을 제거한다. 객체 후보 대응점에 partial affine RANSAC(2px)을 적용해 inlier 수, 비율, 중앙 재투영 잔차 및 3×3 점유를 기록한다. 점유는 매칭 후보의 범위 기준이므로 객체 전체 면적 커버리지 인증은 아니다.
3. 배경은 양쪽 CAD 지지영역 합집합을 151px 커널로 팽창한 영역 밖에서 SIFT 대응점을 추출해 homography RANSAC(2px)을 사용한다. 기준점에서 객체 변환과 배경 변환의 차이를 상대 이동으로 계산한다. 배경 역시 움직이는 기계 부품을 완벽하게 제외한 것은 아니다.
4. 배경의 휴리스틱 품질 통과 조건은 inlier ≥12, 비율 ≥0.5, 화면 4×3 격자 점유 ≥6, 중앙 잔차 ≤2px이다. RANSAC 정합 상태를 거르는 **진단 기준**이며 검증된 신뢰도, 카메라 고정 인증, 이동 판정 임계값이 아니다. 불통과 34개는 상대 이동값이 계산돼 있어도 해석을 보류하고 UI에 FAIL로 표시한다.
5. 객체 ROI의 grayscale ECC 유클리드 정합 점수와 Canny 외곽선 근접 거리도 기록한다. ECC는 주변 물체에 영향받을 수 있고, edge에는 구멍·객체 외곽뿐 아니라 그리퍼 경계가 섞인다. 개별 구멍을 추적하거나 실제 객체 외곽을 분리했다고 주장하지 않는다. GT 회전·병진 변화는 CSV와 HTML의 별도 보조 필드에만 넣었고 자동 판정에 사용하지 않았다.

## 이동량 분포와 불확실성

배경 품질 기준을 통과하고 SIFT/ORB 상대 추정이 모두 있는 65개 경계의 상대 이동 중앙값은 각각 **0.1236px / 0.1155px**, p90은 **16.0189px / 16.0120px**다. 두 방법 추정값 차이의 중앙값은 **0.0932px**, p90은 **0.5313px**다. 이는 CAD ROI 매칭과 추정 변환에서 나온 분포이며, 이동량의 정답·오차 분포가 아니다. 두 방법이 일치해도 둘 다 같은 그리퍼를 추적할 수 있다. [분포 그래프](motion_distribution.png).

실제로 90→93(B027)은 부분 가림이고 배경 품질 FAIL이다. SIFT/ORB가 약 35px에 동의해도 객체가 움직였다고 확정할 수 없다. 235→237(B045)은 수치상 동일 Pose이지만 부분 가림과 배경 FAIL이며, 두 방법의 약 17px 값도 그리퍼가 원인일 수 있다. 109→221(B036)은 SIFT 모델이 만들어지지 않아 정합 후 패널 대신 미정합 이미지로 표시한다. 이런 경우 숫자가 크거나 작아도 사람의 추가 확인이 필요하다.

이동/정지 기준을 임의의 고정 픽셀 값으로 확정하지 않았다. p10·중앙값·p90은 검수 우선순위를 위한 기술 통계일 뿐 분류 임계값이 아니다. 향후 독립 정답이 있는 정지/재배치 쌍에서 오분류 비용에 맞춰 임계값과 불확실 구간을 따로 보정하고, 다른 촬영 시퀀스에서 검증해야 한다. 현 단계에는 안전하게 `LIKELY_MOVED`를 부여할 근거가 없다.

## 검수 우선순위와 안전한 분할

[review_priority.csv](review_priority.csv)는 확인 순서만 제공한다. 배경 품질 실패 P1 34개, 부분 가림 P1 38개, 그 밖의 미확정 P2 26개, 동일 영상 저우선 P3 1개다. 순위가 GT 판정이나 확정 신뢰도를 의미하지 않는다. 한 경계가 여러 위험에 해당할 때 배경 실패를 우선 표시한다.

재배치가 독립적으로 확정되지 않은 경계를 모두 병합하면 인접 그래프 전체가 연결돼 **100장 단일 그룹**이다. 70:30, 80:20 및 그룹 K-fold의 독립 분할은 불가능하다. 이전 64/36은 수치상 Pose와 보수 연결군의 중복이 없을 뿐 실제 물리적 배치의 독립성이 확인되지 않은 후보이며 안전한 확정 split이라고 부를 수 없다. `LIKELY_STATIONARY`도 실제 배치 구분 근거로 사용하지 않는다. 같은 실제 배치가 비인접 구간에 재등장할 수도 있으므로 인접 경계만 검토해도 충분하지 않다.

## 오프라인 검수

`BB100_motion_assist_windows.zip` 전체를 Windows로 복사해 압축 해제한 뒤 `index.html`을 Chrome에서 연다. 각 카드의 첫 줄은 RGB 전후, 겹침, 차영상이고 둘째 줄은 SIFT 정합 후 겹침·차영상과 CAD 후보 ROI 특징점 매칭이다. 정합 실패는 명시한다. CAD 투영 비교와 GT 정보는 접힌 항목에 보조로 제공한다. 자동 분류와 별도로 사람이 경계 `ACCEPT`(재배치), `REJECT`(재배치 아님), `UNCERTAIN`을 입력한다. CSV는 자주 내보내 보관한다. 불확실하면 추측하지 않고 UNCERTAIN으로 둔다. CSV 가져오기에서 이미 편집한 행은 보존된다.

ZIP의 이미지 100개, 패널 99개 및 참조 경로와 압축 무결성을 검증했다. Linux headless Firefox에서 99개 카드/297개 이미지, 기존 CSV 가져오기 충돌 시 편집 보존, CSV 내보내기 내용, 새로고침 복원을 테스트했다. Windows Chrome 실제 실행은 검증하지 못했다. 브라우저 테스트는 격리된 임시 프로필을 사용해 검수 결과를 생성하지 않았다.

## 테스트·다음 단계

합성 대응점에서 알려진 배경 병진과 이상치, 객체 병진에서 배경 병진을 뺀 결과, 4점 미만 실패 처리가 통과했다. 이는 구현의 기하 검사이지 실제 객체 소속이나 이동의 정답 검증이 아니다. 예측 판정은 학습용 GT, 마스크 또는 자동 split 확정에 사용하지 않는다.

신뢰할 수 있는 작업량 절감을 위해서는 가림 없는 객체 특징의 소속을 검증할 수 있는 별도 기준(예: 소량 수동 visible mask와 독립 검수된 이동/정지 쌍, 고정 배경 표식 또는 외부 영상)을 확보해야 한다. 검증된 경계와 비인접 동일 배치를 바탕으로 그룹을 재구성한 후에만 누출 검사를 다시 실시한다. 타깃 및 파인튜닝의 Phase 15 BLOCKED 판정도 유지한다.
