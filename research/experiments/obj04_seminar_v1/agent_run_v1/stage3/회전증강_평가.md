# Stage 3 — 동기 회전 증강 단일 실험

변경: Train crop에 `uniform[-20°,20°]` in-plane 회전만 추가했다. RGB bilinear, Mask·Front/Back XYZ·유효 support nearest, 변환 뒤 HCCE 재생성이다. 기존 Loss는 유효 support를 별도 가중하지 않으므로 이번에도 support는 검증용으로 추적하고 Loss 수식은 바꾸지 않았다.

- CPU 정합성: Train80의0° 입력/라벨 최대차이 0.0; 128/256 affine 차이 0.0; HCCE 복호화 차이 0.0. 독립 CPU 모델 smoke 1 optimizer step 및 두 번째 Loss forward 통과.
- 초기 무작위 모델의 모든 state tensor가 Baseline epoch0과 일치했다. Train80/Val20, seed42, batch4, Adam lr0.0002, AMP, Loss, ValLoss 기반 checkpoint 및 early stopping 규칙을 고정했다. 별도 RNG의 회전 각도는 step 로그에 기록했다.
- 단 1회 GPU 학습: 50epoch, 성공 optimizer 999회, AMP skip 1회, 종료 `early_stop_val_loss`. 주 checkpoint는 PBR ValLoss 기준 epoch10, Baseline은 epoch155다.
- 같은 선택/early stopping 규칙을 사용했지만 **실제 학습 길이와 선택 epoch가 달라** 회전 자체의 순수 효과를 분리해 확정할 수 없다. 추가 checkpoint 선택이나 재학습은 하지 않았다.

학습 후 추가 CPU 검증에서 독립 역 affine 참조의 유효 픽셀 382,368개에 대한 Mask·Front·Back·valid의 최근접 값 불일치는 각각 0개였다. RGB bilinear와 Mask nearest의 합성 표식 16개에서 중심 최대 차이는 128 해상도 기준 0.1693픽셀 미만이었다. 반픽셀 동률 근처 0.05픽셀은 보간 규칙 차이를 피하기 위해 제외했다. 이는 학습 전 필수 게이트와 별도로 실행한 확인이다. [독립 정합성 검사](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/agent_run_v1/checks/augmentation_spatial_independent.json).

## PBR Val20 비교

| 지표 | Baseline | 회전 증강 |
|---|---:|---:|
| Mask IoU | 0.935782 | 0.840029 |
| Front XYZ L2 | 29.4046 | 61.8816 |
| Back XYZ L2 | 29.1845 | 61.7875 |
| Front Z0 hard bit 오류 | 44.57% | 39.25% |
| Back Z0 hard bit 오류 | 43.12% | 47.37% |
| Front 유효 PnP | 20/20 | 0/20 |
| Front ADD@0.1d | 1/20 | 0/20 |
| Front RE 평균(유효 반환) | 81.0261° | 판단 불가 |
| Front TE 평균(유효 반환) | 60.9094 | 판단 불가 |

평균 RE/TE의 '판단 불가'는 0이 아니라 유효 PnP가 0개이기 때문이다. 기준 Mask·XYZ·ADD는 악화됐고 Front Z0 bit 오류만 감소했다. 이는 단일 Z plane 개선이 전체 6D Pose 개선을 보장하지 않는 사례다.

Val에서 예측 Front XYZ의 프레임당 unique 점 평균은 1845.0→75.1, X좌표 표준편차 평균은 25.1331→0.1759이다. 예측 대응점의 X축 붕괴 및 낮은 다양성이 PnP 실패와 양립한다. 이것만으로 회전 증강, checkpoint 선택, 다른 학습 요인 중 단일 원인을 확정하지 않는다.

학습 초기 pseudo-low Loss 문제는 이전 진단에서 확인됐으며 이번에도 epoch10의 낮은 Val Loss가 좋은 좌표를 보장하지 않았다. epoch40의 Val Mask IoU는 0.953287로 기록됐지만, 모델 선택 규칙을 사후 변경하지 않았고 해당 checkpoint로 Pose 평가·추가 실험을 하지 않았다.

## 선택 후 실사27 개발 비교

| 지표 | Baseline | 회전 증강 |
|---|---:|---:|
| 유효 PnP | 27/27 | 5/27 |
| ADD@0.1d | 0/27 | 0/27 |
| 평균 inlier 비율, 실패 포함 | 0.4817% | 0.0390% |
| ADD 평균, 유효 반환만 | 129.0455 (n=27) | 155.7488 (n=5) |
| RE 평균, 유효 반환만 | 151.5618° (n=27) | 136.9421° (n=5) |
| TE 평균, 유효 반환만 | 110.3013 (n=27) | 135.9352 (n=5) |

두 평균의 분모가 다르므로 직접적인 평균 정확도 개선/악화로 비교하지 않는다. 증강 모델이 반환한 동일 5프레임에 한정한 ADD 평균은 Baseline 125.8301→증강 155.7488이나, 작은 선택된 하위집합의 탐색값일 뿐이다. 실사27은 학습·체크포인트 선택·튜닝에 사용하지 않았다.

PnP 구현의 성공/유효 정의는 solver success, R/t 유한, CAD 양의 Z다. 이 정의를 그대로 유지한 Train Front frame83에는 inlier1개와 TE 약6.29e17의 극단적으로 큰 **유한** 값이 포함됐다. 따라서 Train Front의 유효 반환 조건부 ADD/TE 평균은 심하게 왜곡되며, 이를 실용적 Pose 성공으로 해석하지 않는다. NumPy norm overflow 경고가 실행 로그에 기록됐고 CSV의 비어 있지 않은 평가 오차에는 비유한 값이 없음을 별도로 확인했다. 실패 Pose는 분모에서 제외하지 않고 ADD 실패로 센다.
