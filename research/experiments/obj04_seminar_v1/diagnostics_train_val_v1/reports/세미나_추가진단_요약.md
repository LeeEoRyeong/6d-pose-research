# 세미나 추가 진단 요약 — Train 적합도 대 Val 일반화

**핵심 결론:** 좌표 학습이 전반적으로 실패한 상태보다 **분리된 합성 블록에서 좌표 일반화가 실패한 상태**라는 증거가 강하다. Z coarse plane0의 격차가 특히 크다. 재학습은 하지 않았다.

| 지표 | Train80 — 학습 적합도 | Val20 — 개발 검증 |
|---|---:|---:|
| Mask IoU | 0.973965 | 0.935782 |
| Front XYZ L2 | 4.2057 | 29.4046 |
| Back XYZ L2 | 4.5603 | 29.1845 |
| Front Z MAE | 1.3698 | 16.3539 |
| Front Z0 bit 오류 | 2.75% | 44.57% |
| Front ADD@0.1d | 59/80 (73.75%) | 1/20 (5%) |
| Front 실제inlier 비율 | 13.42% | 4.01% |

같은 epoch155 체크포인트를 batch4·AMP·GT BBox crop으로 비교했다. Train 수치는 학습 데이터 적합도이며 일반화 성능이 아니다. Val의 XYZ·Pose는 이전 진단과 프레임별 최대차이 0으로 재현됐다.

## 슬라이드 1 — Train 적합도와 Val 일반화의 차이

- 핵심 문장: “Front XYZ 오차가 Train 4.21에서 Val 29.40으로 약 6.99배 증가했다.”
- 실제 수치: Mask IoU 0.9740/0.9358, Front ADD 73.75%/5%.
- 그림: [좌표 오차 비교](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/diagnostics_train_val_v1/train_val_xyz_error.png), [Mask와 좌표 오차](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/diagnostics_train_val_v1/mask_vs_xyz_comparison.png).
- 설명: Train에서도 일부 오차가 남는다. 다만 양쪽 모두 전반적으로 학습하지 못한 상태보다, 분리된 블록에서의 일반화 격차가 더 크다.

## 슬라이드 2 — Z coarse plane의 일반화 실패

- 핵심 문장: “Z0 오류가 Train 2.75%에서 Val 44.57%로 급증한다.”
- 실제 수치: Back Z0도 3.57%/43.12%. Val Front Z0만 GT bit로 치환한 reference Z MAE는 16.3542→3.2228이다.
- 그림: [Z plane 비교](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/diagnostics_train_val_v1/z_plane_error_comparison.png).
- 설명: 앞 HCCE plane의 오류는 뒤 binary 자릿값에도 전파된다. Fine plane의 50% 오류와 영향이 같지 않다. GT 치환은 Oracle 진단이며 실제 모델 개선이 아니다.

## 슬라이드 3 — 다음에는 회전 증강 하나만 변경

- 핵심 문장: “다른 설정을 고정하고 Train crop에 동기화된 ±20° 회전 증강만 추가해 비교한다.”
- 실제 수치: Train 8블록의 Front 평균 오차 3.17~6.89, Val 2블록은 27.78/31.03.
- 그림: [블록별 오차](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/diagnostics_train_val_v1/block_xyz_error.png), [GT Z 분포](/RESEARCH_DATA/HCCEPose_experiments/obj04_seminar_v1/diagnostics_train_val_v1/gt_z_histogram_comparison.png).
- 설명: 개선 효과는 미확인 가설이다. GT label·Mask에 같은 affine를 적용하고 HCCE를 다시 생성해야 한다. 이번 작업에서는 실행하지 않았으며 실사27로 튜닝하지 않는다.

## 발표 시 제한

- Train ADD는 59/80이며 fine Z plane 잔차도 남는다. “XYZ 학습 완료”라고 말하지 않는다.
- 회전 증강은 제안만 했다. 정확도가 개선됐다는 결과는 없다.
- 단일 checkpoint와 Val 2블록의 비교다. 원인이 Loss·초기화·표본량 중 무엇인지 확정하지 않는다.
- FP16 실제 sigmoid 임계값과 `raw>0`의 작은 차이를 분리했다. 현재 CSV는 실제 원본 임계값 기준이며 기존 Pose 수치는 변하지 않았다.
