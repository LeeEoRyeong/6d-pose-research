# BB100 로컬 검수 방법

`index.html`을 브라우저에서 열거나 서버에서 아래 명령을 실행한다.

```bash
cd /home/oylee/projects/HCCEPose_experiments/bb100_visual_review_20261109
python3 -m http.server 8765 --bind 127.0.0.1
```

서버에서 브라우저를 여는 경우 `http://127.0.0.1:8765/index.html`로 접속한다. 다른 PC라면 SSH 포트 포워딩 등으로 서버의 loopback 포트에 접근해야 한다. 작업 종료 시 서버 프로세스를 중지한다.

1. 우선순위 P1 필터를 선택하고 043/060을 먼저 본다.
2. 이미지를 클릭하면 전체 크기로 열린다. 왼쪽은 보정된 라벨 원본, 오른쪽은 CAD 후보 투영이며 아래는 같은 영역의 확대다.
3. 프레임별 상태(UNREVIEWED/ACCEPT/CORRECT/UNCERTAIN), 가림·반사·경계·흐림, 검수자·시각·메모를 입력한다. 변경은 브라우저 localStorage에만 남는다.
4. **CSV 내보내기**를 눌러 다운로드 파일을 별도 보관한다. 브라우저 데이터 삭제나 오리진 변경에 대비해 자주 내보낸다. 내보낸 CSV의 학습 상태는 항상 HOLD다.
5. UI 사용이 어렵다면 `review_template.csv`를 복사해 편집한다. 원본 템플릿과 GT 파일은 그대로 둔다.

서버에서 실제 브라우저를 이용한 검사는 수행하지 못했다. 브라우저가 localStorage나 다운로드를 차단하면 복사한 CSV를 직접 편집한다.
